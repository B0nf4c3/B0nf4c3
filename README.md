# 👋 Hi, I'm Sh3rl0ck

### Cybersecurity expert focused on web and mobile security, and penetration testing.

I break web and mobile apps to understand how to defend them. Most of my time goes into offensive security practice, CTFs, and learning how real-world systems fail.

---

### 🔭 What I'm working on
- Sharpening offensive skills mostly on **Hack The Box**, plus CTFs.
- Getting deeper into **mobile application security** (Android static and dynamic analysis).
- Building small security tools and automating recon with Python and Bash.
- Documenting what I find in CTF and lab writeups.

### 🎯 Focus areas
- **Web application security** — OWASP Top 10, manual testing, request tampering.
- **Mobile application security** — Android app testing, static and dynamic analysis.
- **Penetration testing** — recon, enumeration, exploitation, post-exploitation.
- **Scripting & automation** — turning repetitive recon into tooling.
